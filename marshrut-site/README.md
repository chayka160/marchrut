# Маршрут возможностей — все файлы сайта

## Содержимое папки

- `index.html` — главная страница с быстрым тестом.
- `css/` — все стили главной страницы.
- `js/` — код главной страницы и быстрого теста.
- `detailed-test.html` — подробный профориентационный тест из 30 вопросов.
- `assets/` — фотографии и значки Lucide.
- `standalone/index.html` — весь сайт с фотографиями и обоими тестами в одном файле.
- `.nojekyll` — файл для публикации без обработки Jekyll.

## Как открыть

Распакуйте архив и откройте `marshrut-site/index.html` в браузере.
Все папки должны оставаться рядом с этим файлом. Шрифты загружаются из Google Fonts.
Если нужен только один файл, используйте `standalone/index.html`.

## Как опубликовать через GitHub Pages

1. Создайте публичный репозиторий GitHub.
2. Загрузите содержимое папки `marshrut-site` в корень репозитория:
   `index.html` должен находиться рядом с папками `css`, `js`, `assets`.
3. Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождитесь адреса опубликованного сайта в разделе Pages.

Альтернатива: загрузите только `standalone/index.html` в корень репозитория
с именем `index.html`. В него уже встроены фотографии, значки и подробный тест.
